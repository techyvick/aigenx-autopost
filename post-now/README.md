# Post now

Upload images here and they're posted to Facebook and Instagram within about a minute.

- **One post:** drop 1–10 images (JPG or PNG) straight into this folder, or put them in a subfolder (each subfolder = one post).
- **Order:** file names decide the slide order: `slide-1`, `slide-2`, …
- **Caption (optional):** add a `caption.txt` file.
- **Only one platform (optional):** add a `platforms.txt` file containing `facebook` or `instagram`.
- **Upload everything in one go** (images + caption.txt together): each upload is posted straight away.

After posting, the files disappear from here and a line is added to `log.txt`.
If something fails, the files stay. Fix the problem, then go to **Actions → Post now → Run workflow** to retry.
